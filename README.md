# Skills for self use

Claude Code skills. Each folder is one skill: `SKILL.md` plus its `references/` and `scripts/`.

| Skill | What it does |
|---|---|
| [new-card-type](new-card-type/) | Add a new card type to the HeartCraft Cards platform (web, iOS/Android apps, video, backend handoff) with the known-bugs catalog and `bug_guard.sh` |
| [new-birthday-template](new-birthday-template/) | Ship a new HeartCraft birthday template across web, both apps, backend, video renderer and template config |

To use one, copy its folder into `<project>/.claude/skills/` or `~/.claude/skills/`.
