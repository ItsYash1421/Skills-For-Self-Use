# Tester checklist — run it BEFORE the tester does

Every row was reported by the tester on a template whose scenes were already pixel-checked. The
pattern is always the same: a chapter looks right while a shared behaviour was hand-rolled or a
wiring point skipped. Phrased as the check, not the advice.

| # | What the tester says | Real cause | The check |
|---|---|---|---|
| 1 | "song play nahi hua" / YouTube pick silent | Receiver hand-rolled `new Audio(...)` instead of `ReceiverSongPlayer` | `grep -n ReceiverSongPlayer components/<key>/*.jsx`; `fallbackSources` must be `BUNDLED_TRACKS.cute` |
| 2 | "replay pe gaana wapas start se nahi" | Replay called `play()` only | replay = `restart()` (seeks `startSec`) then `play()`; RN preview wrap → `setCurrentTime(startSec)` + `onReplay` |
| 3 | "app button playstore/appstore nahi kholta" | CTA opened the website | `grep -rn resolveAppStoreLink components/<key>/` and pass `navigator.maxTouchPoints` |
| 4 | "screen pe fit nahi, gap chaaron taraf / left-right kat raha" | No scale-to-fit, or stage clipped, or measured with `getBoundingClientRect` inside a scaled parent | `ResizeObserver` + `clientWidth/Height`; cover-behind + contain-in-front; `.stage {overflow: visible}`; check 390×844, 390×700, 1280×720 |
| 5 | "background mein seam / band" | An overlay sized to the card while the backdrop covers the screen; or two differently scaled backdrop copies | full-bleed layers use the COVER box; backdrop drawn once |
| 6 | "letter type hota hai par height nahi badhti / scroll nahi" | Fixed box, no auto-scroll | `useTypewriter` + `overflow-y:auto` + scrollTop=scrollHeight (web); ScrollView `maxHeight` + `scrollToEnd` (RN) |
| 7 | "photo kat rahi hai" | `cover` on user photos | `object-fit: contain` / `resizeMode="contain"` on every user photo |
| 8 | "explore more / cards ka ad frame mein set nahi" | Shelf in the reference's fixed slot; absolute tops on a short screen | finale = flow stack (`end-stack`), shelf `height:auto`, 3×2 real icon tiles, art moved under it |
| 9 | "text/button ek dusre ke upar" (short phone) | Absolute design tops | that chapter is a flex column in the screen box with `overflow-y:auto` |
| 10 | "button art ke niche chala gaya" | z-index below the chapter's art | CTA above the art band |
| 11 | "sab ek saath ud gaye" | A CTA that completes a game in one go | stagger on the timeline's per-item beat, clear timers on unmount |
| 12 | "mute button kaam nahi karta beech ke chapters mein" | `muted`/`onToggleMute` passed only to first/last scene | thread through the router's `common` props |
| 13 | "tile app mein nahi dikh raha" | No ManKiBaat row (no bypass exists) — or the app build predates the preview | curl the config; check the build number |
| 14 | "All Themes mein template nahi" | Missing from `LOCAL_THEMES` / `PREFIX_TO_TEMPLATE` | `grep <ID> BirthdayThemeRegistry.tsx` in both apps |
| 15 | "video nahi bani, baaki ki ban rahi" | id not in the DEPLOYED `videoRender.supportedTemplates`, or renderer image predates the template | `git show <BE tag>:…application.properties`; `git ls-tree -r --name-only <video tag> \| grep templates/<id>`; BQ completed rows (kebab id) |
| 16 | "video section hi nahi dikh raha" | no render job → no `videoStatus` → section hidden by `orderHasVideo()` | BQ `video_renders` by `shortcode` (no rows = never enqueued). NOT `curl /v/<code>`: it is 404 for every template, rendered cards included (checked 2026-10-01) |
| 17 | "link localhost dikha raha" | prefix missing from `shareUrl.js` allow-list / app regex maps | add the letter; `shareUrl.test.js` |
| 18 | "font alag lag raha" | font not bundled (web `next/font/local`; RN needs native rebuild + PostScript name = filename) | check `document.fonts` / the iOS `UIAppFonts` list + a rebuild |
| 19 | "analytics galat template dikha rahi" | a two-way `=== 'cute' ? … : …` ternary somewhere | grep the sender for every such ternary |
| 20 | "preview mein scene kat gaya / jump kar gaya" (simulator) | screenshots lag, not the timeline | prove with a temporary Metro log, then delete it |
| 21 | "purana asset dikh raha" | `/public` cached 30 days | `?v=N` on re-cut assets |
| 22 | "edit ke baad link galat prefix" | BE rewrites the prefix asynchronously | `EDIT_PREFIX_FOR_TEMPLATE` mirror in the app success screen |
| 23 | "letter mein 'Dear' do baar" | The sender's default letter already opens "Dear {name}," and the letter chapter prints its own greeting | skip the salutation when `/^dear\b/i` matches the message (web + RN) — butterfly, 2026-09-29 |
| 24 | "web preview mein template nahi / ya launch se pehle dikh gaya" | The web sender has TWO pickers: `BPreviewScreen` (control) and `BPreviewCarousel` (passcode cohort, live). | 25 | (dev warning) `Invalid props.style key transformOrigin supplied to Image` | RN 0.73 prop-types | put `transformOrigin` + transform on a wrapping `View`, keep the `Image` plain |
| 26 | "timer / passcode screen pink hai, template jaisa nahi" | New template mapped to an existing gate skin (`cute`) | give it its own skin in ALL gate maps: web `CountdownGate.jsx` (SKINS, LINES, decor), `PasscodeLock.jsx` (SKINS, decor, `/passcode/<skin>/{line,close}.svg`), `PasscodeLock.css` + `CountdownGate.css` blocks, `countdownAssets.js`, `PreviewScanStep.css`; RN `BirthdayCountdownIntro.tsx` (12 maps + `OPENS_WITH_SCAN`) |
| 27 | RN test suite dies with `Cannot read properties of undefined (reading 'IsAndroid')` | A shared module (the intro gate) imported something from the heavy preview, which requires `react-native-sound` | keep reusable glyphs in a light module (`ButterflyGlyph.tsx`); never import a preview from a shared component |
| 28 | (QA) "intro screen nahi aa raha after switching chip" | The app carousel keeps every chip mounted; the intro replays only when the story loops to its QR opening | wait one loop (~40 s), don't add a remount |

Then run `scripts/audit_template.sh … --live` and paste its MISSING lines into the template memory
as the to-do list. A template is "done" when the script is clean, BQ shows a completed render, and
the memory file's status table cites the commit/tag/curl for every row.
| 29 | "transitions smooth nahi" — outgoing screen blinks/teleports during a page turn | The turn copies the old scene as an HTML snapshot; new DOM nodes restart every CSS animation (fill-mode `both` entrances go to opacity 0, flock paths jump) | keep the old React element MOUNTED in a second slot for the turn (two fixed slots ping-pong, `pointer-events:none` on the out slot) — measure with `getComputedStyle` 100 ms into a turn |
| 30 | RN preview cuts between chapters while web slides | RN preview only had a per-scene fade | port `useSceneSlide`+`SlideScreen` from BirthdayWishPreview; key the slide on `${run}-${scene}`; video `Block` needs `prev` for the same slide |
| 31 | "photo frame cut" on a template whose frame is an ART asset | photo box drawn OVER the art as its own card, sized from Figma's photo layer (which Figma masked) | flood-fill the art's alpha to find the window quad, put a cream card UNDER the frame and the `contain` photo in the largest rect inside the window; pin card/window/z-order in jest |
| 32 | "desktop pe bg fit nahi hua" on the title / gate screens only | those screens are built from edge PIECES over a base colour; a 16:9 box is ~1480 card px wide and the per-piece cover cap cannot reach; gate decor is card-relative inside the scaled stage | add blurred `background-size: cover` pseudo-layers of the same pieces behind (`.bf-bg--<scene>::before/::after`, `.pcl--<skin> .pcl-bg::before/::after`); check every piece-built screen AND both gates with headless Chrome at 1600×900 (`--timeout=12000`), the Browser pane cannot show a desktop viewport |
| 33 | "payment pe gaya, wapis aaya to music nahi chala; template change karne pe chala" | Preview demo uses its own `<audio>` tag → unmounted by the payment screen's early return → the fresh element is refused `play()` without a tap (iOS Safari / IG webview; desktop Chrome hides it) | `const audioRef = usePreviewTrack('<key>', sources)`; prove it in the iOS simulator's Safari against a mock BE (see [[birthday-passcode-countdown]]) |
| 34 | RN preview crashes with "Rendered more hooks than during the previous render" when a chapter exits | an enter/animation hook called inside a branch of the scene (`if (open) useEnter(...)`) | hoist every hook to the top of the scene; the loop test (walk the whole story twice) is what catches it — zodiac, 2026-09-30 |
